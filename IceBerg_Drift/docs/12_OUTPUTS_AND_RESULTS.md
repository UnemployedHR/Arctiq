# Outputs and Results

This document explains where the system saves generated files and how to interpret them.

## 1. Data and Features
**Location:** `data/ml/`
* `final_ml_dataset.parquet`: The master dataset containing all engineered features and target displacements for every valid trajectory segment.
* `ml_dataset_config.json`: Schema defining exactly which columns are features vs targets.

## 2. Trained Models
**Location:** `models/`
* `baselines/*.joblib`: Saved scikit-learn models (Ridge, GBR) and the StandardScaler.
* `gru/best_model.pt`: Saved PyTorch weights for the GRU model.
* `hybrid/*.joblib`: Saved Hybrid GBR residual correction model.

## 3. Evaluation Metrics
**Location:** `models/` (JSONs) and `reports/` (Markdown)
* `models/final_test_results.json`: Raw dump of mean, median, RMSE, min, and max geodesic errors for every model on the test set.
* `reports/*.md`: Auto-generated markdown reports containing formatted tables of the JSON metrics.

## 4. Visualizations
**Location:** `figures/`
* `model_comparison.png`: A bar chart comparing Mean, Median, and RMSE errors across all evaluated models.
* `error_distributions_all.png`: Histograms showing the distribution of prediction errors (capped at 95th percentile for readability).
* `trajectory_divergence.png` / `trajectory_bridge_analysis.png`: Plots from diagnostic scripts showing how interpolation affects paths.

## 5. Physics Simulation Outputs
**Location:** `data/results/` (and root dir for temp diagnostics)
* `real_run_24h.nc`: The raw NetCDF output from OpenDrift containing full particle states.
* `real_run_24h.csv`: A tabular dump of Time, Particle ID, Lat, and Lon.
* `real_run_24h.png`: A map visualization generated by OpenDrift plotting the simulated path.
