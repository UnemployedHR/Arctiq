# Results

This document summarizes the actual held-out test results generated by `final_evaluation.py`.

*(Note: These figures represent the current state of the ML models on the processed IIP trajectory segments.)*

## Held-Out Test Set Performance

| Model | Mean Error (km) | Median Error (km) | RMSE (km) |
|-------|-----------------|-------------------|-----------|
| **Persistence (Baseline)** | 24.36 | 17.58 | 32.74 |
| **Ridge Regression** | 22.84 | 16.55 | 30.29 |
| **Gradient Boosting** | 22.14 | 15.93 | 30.13 |
| **Hybrid Physics + ML** | 21.68 | 15.65 | 29.80 |
| **GRU** | 22.18 | 15.82 | 30.17 |

*Note: Depending on random seeds, hardware, and exact dataset configurations during setup, minor variances in decimals may occur.*

## Interpretation
* **Persistence** sets the baseline: assuming the iceberg maintains its previous velocity yields ~24 km of mean error.
* **Machine Learning** models (Ridge, GBR, GRU) successfully learn patterns that beat persistence, reducing error to ~22 km.
* **Hybrid Physics+ML** slightly edges out the pure ML models, demonstrating that injecting a mechanistic prior (even a simplified scaled-persistence proxy) helps the Gradient Boosting trees make better predictions.

## Physics Model Reference Limitation
* **Important:** There is NO population-level test result for the pure OpenBerg physics model here.
* Running OpenBerg requires massive NetCDF environmental files for every iceberg, which is computationally prohibitive in this prototype.
* **Reference Point:** A single-iceberg test on Iceberg 20857 over a 7-day period (June 2 to June 9, 2021) yielded an OpenBerg surface-only error of **30.01 km**. This is documented in `FORCING_ATTRIBUTION_7DAY.md` but *cannot* be directly compared to the population-level ML statistics above.
